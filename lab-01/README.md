## Objective

To create a web server using Node.js and Express.js and implement different GET routes.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- npm

## How to Run

1. Clone the repository.
2. Open the lab-01 folder.
3. Install dependencies:

   npm install

4. Start the server:

   npm start

## Endpoints

| Method | Path | Description | Status |
|---|---|---|---|
| GET | / | Welcome message | 200 |
| GET | /about | Student information | 200 |
| GET | /time | Current date and time | 200 |
| GET | /unknown | Not found message | 404 |
